# Mauve Method

A thoughtful pair of color themes for Visual Studio Code.

## Included themes

### Mauve Method Mist

A light theme built around soft mauve surfaces and focused contrast.
![Mauve Method Mist](images/previews/mist.png)

### Mauve Method Smoke

A dark theme built around deep mauve surfaces and restrained contrast.
![Mauve Method Smoke](images/previews/smoke.png)

## Installation

### Install from a VSIX file

1. Download the latest `.vsix` file from the repository’s GitHub Releases page.
2. Open Visual Studio Code.
3. Open the Command Palette.
4. Run **Extensions: Install from VSIX...**
5. Select the downloaded file.

You can also install it from the command line:

```sh
code --install-extension mauve-method-0.1.0.vsix
```

## Selecting a theme

Open the Command Palette and run:

```text
Preferences: Color Theme
```

Then select either **Mauve Method Mist** or **Mauve Method Smoke**.
