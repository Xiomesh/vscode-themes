# Blueprint Themes

A precise family of color themes for Visual Studio Code.

## Included themes

### Blueprint Carbon

A restrained dark theme built around carbon-black surfaces, titanium-gray structure, and deliberate blue accents.

Blueprint Carbon is designed to feel:

- Clear
- Engineered
- Modern
- High-contrast without feeling neon
- Suitable for long coding sessions

## Installation

### Install from a VSIX file

1. Download the latest `.vsix` file from the repository’s GitHub Releases page.
2. Open Visual Studio Code.
3. Open the Command Palette.
4. Run **Extensions: Install from VSIX...**
5. Select the downloaded file.

You can also install it from the command line:

```sh
code --install-extension blueprint-0.1.0.vsix
```

## Selecting the theme

Open the Command Palette and run:

```text
Preferences: Color Theme
```

Then select:

```text
Blueprint Carbon
```

## Future themes

Blueprint Paper, a light counterpart to Blueprint Carbon, is planned for a future release.
