# Mindful Themes

A calming family of color themes for Visual Studio Code.

## Included themes

### Mindful Curiosity

A warm dark theme built around soft charcoal surfaces, muted terracotta accents, and calming teal details.
![Mindful Curiosity](images/previews/curiosity.png)

### Mindful Insight

A gentle light theme with warm paper surfaces, grounded brown text, and restrained therapeutic accents.
![Mindful Insight](images/previews/insight.png)

## Installation

### Install from a VSIX file

1. Download the latest `.vsix` file from the repository’s GitHub Releases page.
2. Open Visual Studio Code.
3. Open the Command Palette.
4. Run **Extensions: Install from VSIX...**
5. Select the downloaded file.

You can also install it from the command line:

```sh
code --install-extension mindful-0.1.0.vsix
```

## Selecting the theme

Open the Command Palette and run:

```text
Preferences: Color Theme
```

Then select either:

- Mindful Curiosity
- Mindful Insight
